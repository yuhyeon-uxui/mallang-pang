# 💥 말랑 팡팡 (Mal-lang Pang)

바탕화면 구석에 띄워놓고 언제든 타격하여 스트레스를 풀 수 있는 '솜사탕 왁스볼' 데스크탑 스크린 메이트 앱입니다. 일렉트론(Electron)으로 제작되어 투명한 배경으로 바탕화면 위에 상주합니다!




## ✨ 주요 기능
- **찰진 타격감**: 마우스로 클릭할 때마다 "빠지직!" 부서지는 왁스볼의 ASMR 사운드!
- **동적 보로노이 파편화**: 내가 클릭한 정확한 위치를 중심으로 껍질이 조각조각 부서지며 수축하는 리얼한 물리 효과.
- **슬라임 모드**: 8번 타격하여 껍질을 다 부수고 나면, 쫀득하게 늘어나는 슬라임 모드로 변신! 드래그하여 고무줄처럼 당겨보세요.
- **다양한 테마**: 파스텔 솜사탕, 두바이 쫀득 초코, 민트 초코 등 매번 꺼낼 때마다 랜덤한 색상의 장난감이 등장합니다.

## 🚀 설치 및 실행 방법

### 1. 일반 사용자용 (추천)
우측의 **[Releases]** 탭에서 본인의 운영체제에 맞는 최신 버전을 다운로드하세요.
- **Mac (맥북)**: `mallang-pang-X.X.X.dmg` 다운로드 후 설치
- **Windows (윈도우)**: `mallang-pang-X.X.X.exe` 다운로드 후 실행

> [!WARNING]
> **설치 시 주의사항 (Windows & Mac 공통)**
> 본 앱은 개인이 취미로 제작한 무료 앱으로, 공식 스토어 인증서가 포함되어 있지 않아 보안 경고창이 뜰 수 있습니다. 절대 바이러스가 아니니 안심하세요!
> 
> 🪟 **Windows (윈도우) 해결법**
> 1. 브라우저에서 다운로드를 차단하는 경우: `...` (또는 경고 아이콘) 클릭 -> `유지` -> `그래도 계속` 클릭
> 2. 실행 시 파란색 경고창(SmartScreen)이 뜨는 경우: 파란 화면 중간의 **`추가 정보`** 클릭 -> 우측 하단에 나타나는 **`실행`** 버튼 클릭
> 
> 🍎 **Mac (맥북) "손상된 앱" 에러 해결법**
> 1. `.dmg` 파일을 열고, 말랑팡팡 아이콘을 반드시 옆에 있는 **`Applications (응용 프로그램)`** 폴더로 드래그해서 옮깁니다.
> 2. `Cmd + Space`를 눌러 **`터미널(Terminal)`**을 검색해서 실행합니다.
> 3. 터미널 창에 `xattr -cr /Applications/말랑팡팡.app` 을 복사+붙여넣기 하고 엔터를 칩니다. (비밀번호 입력 시 화면에 안 보여도 정상 입력됩니다)
> 4. 다시 응용 프로그램 폴더에서 말랑팡팡을 실행하시면 정상 작동합니다!

### 2. 개발자용 (직접 빌드)
Node.js가 설치되어 있어야 합니다.
1. 이 저장소를 클론(다운로드)하거나 우측 상단의 `Code -> Download ZIP`으로 다운로드 후 압축을 풉니다.
2. 터미널에서 해당 폴더로 이동한 후 패키지를 설치하고 실행합니다:
   ```bash
   npm install
   npm start
   ```

## 🎮 조작 방법
- **좌클릭**: 왁스볼 타격 (총 8회 타격 시 슬라임 모드 진입)
- **마우스 드래그 (타격 전)**: 바탕화면 내 원하는 위치로 이동
- **마우스 드래그 (슬라임 모드)**: 캐릭터를 치즈나 고무줄처럼 쫀득하게 늘리기
- **우클릭**: 메뉴 열기 (`새 왁스볼 꺼내기`, `앱 닫기`)
