# 💥 말랑 팡팡 (Mal-lang Pang)

바탕화면 구석에 띄워놓고 언제든 타격하여 스트레스를 풀 수 있는 '솜사탕 왁스볼' 데스크탑 스크린 메이트 앱입니다. 일렉트론(Electron)으로 제작되어 투명한 배경으로 바탕화면 위에 상주합니다!




## ✨ 주요 기능
- **찰진 타격감**: 마우스로 클릭할 때마다 "빠지직!" 부서지는 왁스볼의 ASMR 사운드!
- **동적 보로노이 파편화**: 내가 클릭한 정확한 위치를 중심으로 껍질이 조각조각 부서지며 수축하는 리얼한 물리 효과.
- **슬라임 모드**: 8번 타격하여 껍질을 다 부수고 나면, 쫀득하게 늘어나는 슬라임 모드로 변신! 드래그하여 고무줄처럼 당겨보세요.
- **다양한 테마**: 파스텔 솜사탕, 두바이 쫀득 초코, 민트 초코 등 매번 꺼낼 때마다 랜덤한 색상의 장난감이 등장합니다.

## 🚀 설치 및 실행 방법

Node.js가 설치되어 있어야 합니다.

1. 이 저장소를 클론(다운로드)하거나 우측 상단의 `Code -> Download ZIP`으로 다운로드 후 압축을 풉니다.
2. 터미널(또는 명령 프롬프트)에서 해당 폴더로 이동한 후 필수 패키지를 설치합니다:
   ```bash
   npm install
   ```
3. 앱을 실행합니다:
   ```bash
   npm start
   ```

## 🎮 조작 방법
- **좌클릭**: 왁스볼 타격 (총 8회 타격 시 슬라임 모드 진입)
- **마우스 드래그 (타격 전)**: 바탕화면 내 원하는 위치로 이동
- **마우스 드래그 (슬라임 모드)**: 캐릭터를 치즈나 고무줄처럼 쫀득하게 늘리기
- **우클릭**: 메뉴 열기 (`새 왁스볼 꺼내기`, `앱 닫기`)

## 🛠️ 기술 스택
- Electron, Node.js
- Vanilla HTML / CSS / JavaScript
- Voronoi Algorithm (`voronoi` 패키지)
- Web Audio API
